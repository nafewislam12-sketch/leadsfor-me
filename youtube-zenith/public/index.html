Run on GitHub Actions (Multiple IPs)

GitHub Actions provides fresh, rotating datacenter IPs on each runner, allowing you to bypass YouTube rate limits completely!

Step 1: Push workflow to your repo
git add . && git commit -m "Add Zenith Scraper" && git push
Step 2: Trigger via GitHub Web UI or CLI

Go to your GitHub repo > Actions > Zenith YouTube Lead Scraper > Run workflow.

gh workflow run zenith_scraper.yml -f niches="b2b saas, real estate coach" -f workers="5" -f max_channels_per_worker="50"
Step 3: Download Aggregated Leads

When completed, download the consolidated zenith_leads_master.xlsx and zenith_leads_master.csv artifact directly from the run summary!
